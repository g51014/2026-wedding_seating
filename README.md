# 阿武喜宴場地桌次

2026/10/4 江林府喜宴（The Grand Ballroom I）場地桌次圖。男方名單依《確認版-阿武喜宴桌次名單(V2)1150828》填入。

## 怎麼看

- **紅點 = 1 號位**（近舞台左上），其餘順時針。
- **主桌 12 席**；其餘圓桌 10 席。場地無 4 號桌。
- 男方已排：主桌、第 1–3、5–9 桌。第 10、11 桌待填。12–22 桌為場地空桌。
- 第 8 桌張厚齊為素食。主桌 7 號張榮興為證婚人，坐新郎新娘正對面。
