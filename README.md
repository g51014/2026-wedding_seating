# 阿武喜宴場地桌次

1004 江林府喜宴（The Grand Ballroom I）完整場地桌次圖。桌位依現場平面圖重繪，不沿用其他草稿桌號。

## 怎麼看這張圖

- **紅點 = 1 號位**：對應場地圖上近舞台、桌緣左上的紅點。
- **2–10 號位**：由 1 號位順時針排列。
- 場地圖有 **主桌 + 1–3、5–22 桌**（無 4 號桌），每桌 10 席，共 220 席。
- 點圓桌可查看該桌座位並填入賓客姓名；可用搜尋找人，也可列印或匯出 JSON。

## 本機執行

```bash
npm install
npm run dev
```

瀏覽器開啟 [http://localhost:43127](http://localhost:43127)。

## 匯入名單

Word 桌次可用「匯入名單」帶入（JSON 或純文字）。文字格式範例：

```
主桌
1 新郎
2 新娘

1桌
1 王小明
2 王太太
```

姓名會存在瀏覽器本機，不會上傳到伺服器。
